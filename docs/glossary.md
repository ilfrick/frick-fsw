# Glossary

| Document id | FRICK-GLOS-001 |
| ----------- | -------------- |
| Revision    | 0.4 |
| Date        | 2026-10-14 |

| Term | Definition |
| ---- | ---------- |
| MPL-2.0 | Mozilla Public License version 2.0; owner-authorized for original project-authored code and materials (norm N13); NC-EXT-43 remains open for external/generated boundaries and combined-distribution compatibility. |
| AGPL-3.0 | GNU Affero General Public License v3; former project license, retained in historical records and prior distribution notices. |
| APID | Application Process Identifier (CCSDS Space Packet). |
| BSP | Board Support Package (RTEMS). |
| CCSDS | Consultative Committee for Space Data Systems. |
| CUC | CCSDS Unsegmented Time Code - binary time encoding. |
| DDJF | Design Description and Justification File: the comprehensive description of the frick-fsw framework and of the accessory repository elements, kept current at every release (`docs/engineering/software-description.md`, FRICK-ENG-0007). |
| ECSS | European Cooperation for Space Standardization. |
| EVS | Event Services (cFS/ES mapping in frick-fsw). |
| ES | Executive Services (application registry/lifecycle in frick-fsw). |
| FSW | Flight Software. |
| GAP-AX | Documented residual gap to ECSS class A (norm N5). |
| ICD | Interface Control Document. |
| Lean | Lean 4 theorem prover used for frame-level verification (norm N1). |
| MPFS | Microchip PolarFire SoC family; RTPFS160ZT is the radiation-tolerant variant (FCVG784). |
| NC | Non-Conformance raised by a review; closed per norm N12. |
| PAL | Portable Abstraction Layer (OSAL equivalent). |
| PUS | Packet Utilisation Standard; PUS-C = ECSS-E-ST-70-41C. |
| RSB | RTEMS Source Builder (toolchain build). |
| RTEMS | Real-Time Executive for Multiprocessor Systems; version 6.2 (open-source RTEMS 6.2). |
| SB | Software Bus (publish/subscribe, cFS-style). |
| SES | Software Engineering Support (ECSS-Q-ST-80). |
| SRS / SSS | Software Requirements Specification / Software System Specification (backwards ECSS docs, norm N3). |
| TBL | Table Services. |
| TC / TM | Telecommand / Telemetry. |
| TIME | Time Services (UTC correlation, CUC). |
| V&V | Verification & Validation (norm N6). |
| Wildcard | `FF_SB_WILDCARD` (0xFFFF) subscription matching every message id. |
