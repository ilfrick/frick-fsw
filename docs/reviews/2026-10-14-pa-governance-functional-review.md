## 1. Scope

This PA review covers all uncommitted changes in the working tree since the last approved baseline (commit 57974d2). The review assesses:

1. **Governance changes**: Addition of non-derogable norms N21 (Functional-issue-only correction and non-blocking NCs) and N22 (Requirement-based and integration testing with expected-result oracles) in `docs/rules.md` rev 2.6, with corresponding updates across AGENTS.md, README.md, sprint-plan.md, handover.md, loop-audit.md, and CHANGELOG.md.

2. **License transition**: Project owner authorization of MPL-2.0 for original project-authored code/materials (replacing AGPL-3.0-only), reflected in LICENSE, NOTICE, SPDX headers across 100+ files, ADR-0011, and licensing.md.

3. **Functional code changes**: CCSDS decoder PDL validation enhancement (`src/transport/ccsds/ccsds.c`) addressing NC-EXT-01; new PUS-C over IP/TSN round-trip demonstration tests (`tests/unit/test_link_ip.c`, `tests/unit/test_link_tsn.c`); new CCSDS decoder boundary tests (`tests/unit/test_r2_gap.c`); removal of tautological assertions (`tests/unit/test_time.c`, `tests/unit/test_gptp.c`); RX length semantics documentation (`src/transport/link/link_tsn.h`).

4. **Process/tooling/documentation changes**: CI workflow updates; `tools/scripts/metrics.py` verdict classifier overhaul; `docs/vv/tool-qualification.md` status updates; `docs/requirements/traceability.yaml` updates; new T21 license checker (`tools/scripts/license_check.py` + tests).

5. **NC register updates**: NC-EXT-47 added for N22 test-evidence mapping; NC-EXT-46 for deferred status findings under N21.

Per N21, every finding is classified as **[FUNCTIONAL]** (affects correct/intended software behavior) or **[NON-FUNCTIONAL]** (documentation/metadata/process/evidence-gaps/review comments that do not change software behavior). Non-functional findings do not block review conclusion; only functional findings require immediate correction with regression test/verification.
